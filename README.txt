MISE A JOUR GITHUB PAGES

1. Exporter une sauvegarde depuis l application AVANT toute modification.
2. Dans le depot GitHub, remplacer les 5 fichiers index.html, sw.js, manifest.webmanifest, icon-192.png et icon-512.png a la racine (pas le dossier ni le ZIP).
3. Valider Commit changes et attendre la publication.
4. Ouvrir le site dans Safari, puis fermer et rouvrir l application installee.
5. Les anciennes quantites et objectifs globaux sont conserves. Chaque taille peut maintenant avoir son objectif propre.
6. Ne pas effacer les donnees de Safari et ne pas desinstaller l application sans sauvegarde.

Les tailles disponibles sont 6, 9, 12, 18, 24 et 36 mois.
